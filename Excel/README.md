# SQL Queries

The SQL queries used to extract revert PRs from the AIDev SQLite database are provided as text files. To run them:

1. Download the AIDev dataset from Hugging Face and open the .db file in DB Browser for SQLite
2. Navigate to the Execute SQL tab
3. Copy and paste the contents of the .txt file into the query editor
4. Click Run (or press F5)
